## HTML 文档站约定

- 顶部一级导航固定为：`文档中心 / 工作台 / 需求方案 / 技术方案 / 架构总览 / 协作机制 / 主方案`
- 一级导航只做页面切换，不混入页内锚点、系统入口或临时快捷操作
- 页内快捷操作统一放在 hero 区或正文
- Markdown 负责真相源，HTML 负责清晰查看和图示表达
- 后续新增 HTML 页面时，默认复用这套导航和层级
