关键工程规范
① LLM 同步/异步边界（强制）：FastAPI async handler 里**禁止**直接调同步 client.chat， 必须 await asyncio.to_thread(fn)，否则阻塞整个事件循环。
② 任何 LLM 输出都要有"看得到的回退路径"：出题、判分、周计划、学习手册都有 fallback，不静默失败。
③ venv 不进 iCloud：源码可同步，但 venv / 运行时数据必须放本地非同步路径（启动卡死的根因）。
④ 多端联通：一个后端、一份数据、多通道触点：提醒做成 web 自身能力（PWA + Web Push，邮件兜底），与公众号解耦。V0.5 先预埋 ReviewItem schema + /today /review/* 接口，V1 再上 Web Push + APScheduler。
评估闭环：对话挖掘目标 → evaluator 出题 → 双坐标答题 → scorer 判分 → profiler 画像 → generator 弱项加权生成路径。
推送链路(V1)：APScheduler 每日定时 → 算今日任务+到期复习 → pywebpush 下发 → service worker 弹通知 → 点开 PWA 完成 → POST /api/review/submit 回写。
