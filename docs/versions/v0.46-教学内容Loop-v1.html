让 LearnBuddy 生成真正能学的单节内容

V0.46 的核心不是把 prompt 写长，而是建立单节内容的可控生产线：先理解学习目标，再收集来源，再设计教学链，再生成互动内容，再用质量门评审和返工，最后把内容渲染成用户真的能学的一节课。

状态：已开发提交：74180b6回归：259 passed

需求方案

把“AI 生成一段讲解”升级为“生成一节可学习任务”。

  • 第一天内容默认可用，用户进入学习页能直接开始。
  • 每节课围绕一个明确问题，不再堆大段泛泛讲解。
  • 来源可以包含网页、官方文档、论文/书刊、视频和 B 站链接。
  • 每个环节都有学习动作：判断、看懂、复述、动手、练习、收束。
  • 已学环节可回看，用户可带要求重新生成。

技术方案

用受控 LessonBuildGraph 替代一次性 prompt。

  • ResearchPack 负责资料收集、来源分类和置信度。
  • LessonSpec 负责本节目标、难度、边界和教学链设计。
  • LessonFlow 负责 8 环节内容、互动题、产出任务和来源引用。
  • QualityReport 负责深度、来源、互动、可读性和风险评审。
  • LessonRuntime 负责状态、回看、输入、结构图和持久化。

开发范式

每个生成节点都要可观察、可失败、可返工。

  • 先定义数据契约和 fixture，再接模型生成。
  • 先单节闭环稳定，再优化页面体验。
  • 质量门不过就预算内返工，仍失败则保存原因。
  • 前端必须展示生成阶段，不能让用户盲等。
  • 浏览器截图验收学习页，不只看 JSON。

核心问题映射

V0.46 只解决“单节学习内容是否值得学”，不把路径重规划提前混进来。

Problem Matrix
核心问题产品需求技术方案验收信号
内容太浅每节课围绕一个真实学习问题展开，必须有概念边界、关键规则、真实例子、常见误区和产出任务。LessonSpec 明确 learning_question、learning_outcome、depth_level、must_cover、avoid_generic；QualityReport 检查 depth_score。随机生成 3 个领域课程，用户能说出“本节解决什么、学完能做什么”。
来源弱用户能看到内容依据，不再只看到“AI 生成”。技术、行业、学术、政策类主题默认检索来源。ResearchPack 记录 source_type、title、url、authority、used_for、confidence；SourceSelector 过滤低质来源。每节课至少 3 条有效来源或明确失败原因；来源能在学习页展示。
互动像摆设每个互动都要服务学习判断，不能只是“点一下继续”。选项和补充输入分离。LessonFlow.cards 使用 interaction_type、expected_signal、user_answer、feedback_rule；前端保存选择和输入两个字段。切换选项不会覆盖输入框；完成后能回看自己的选择和产出。
学习页看不出节奏用户知道当前处在 8 个环节的哪一步、为什么做这一步、下一步是什么。LessonRuntime 保存 current_step、completed_steps、step_outputs；渲染器按 step_type 选择组件。已学环节可点击回看；刷新后仍停留在当前环节。
生成过程像卡死生成页展示“正在理解、搜索、设计、生成、质检、保存”，失败可重试。LessonBuildRun 记录 node_status、started_at、finished_at、error_code；前端轮询 run status。不会出现长时间只有一个 spinner；超时后给失败原因和重试入口。
结构图不可读架构图、流程图、对比图用可读视觉组件呈现。DiagramCard 使用 diagram_schema 生成 SVG/HTML，不再直接渲染 ASCII 图。桌面和移动端无横向滚动；图中节点文字可读。
旧数据兼容风险旧路径仍可打开，缺少新字段时降级展示。LessonAdapter 为旧 explain/practice/produce 转换到最小 LessonFlow；schema_version 懒初始化。线上旧实例不报错；缺少 cards 时仍能展示旧内容。

开发准入补强

基于需求评估体系，V0.46 进入开发前必须补齐这些工程化约束。

Readiness Gate
缺口补强动作产出物验收标准
缺少内容质量基准建立 20-30 条 golden set，覆盖 AI 技术、英语、写作、营养、考试、职业转型等不同领域；每条包含学习目标、用户水平、期望深度和反例。lesson_quality fixture / 评测说明每次调整生成链路后都能跑同一批样本，避免“看起来变好但不可复现”。
QualityReport 阈值不够硬为 depth、source_coverage、interactivity、clarity、operability、safety 设定最低阈值和返工条件。质量评分 rubric低于阈值自动返工一次；返工后仍不达标时保存失败原因和可重试入口。
接口边界不清先定 build/status/read/runtime/regenerate 五类接口，再开发前端组件。最小 API 契约前端不直接猜文件状态；刷新、退出、重进都能从接口恢复。
旧数据兼容不确定准备旧 explain/practice/produce 数据样例，用 LessonAdapter 转成最小 LessonFlow。legacy lesson fixture历史学习路径仍可打开，缺少新字段时降级展示而不是报错。
学习页状态没有闭环明确 ready、generating、failed、running、completed、reviewing、regenerating 七种状态和按钮行为。学习页状态矩阵不会出现用户不知道“现在能不能学、是不是卡死、是否已保存”的状态。
来源策略容易泛化把来源分成“本节直接依据、延伸阅读、视频参考、备用来源”，视频和 B 站链接允许作为参考内容但不替代事实来源。SourcePack 分类规则技术/行业/学术主题默认有外部来源；无来源时必须显示原因。

最小接口草图

V0.46 不要求一次性后端完美，但必须让前端、生成任务和恢复机制有清晰契约。

API Contract
接口用途必须返回 / 保存失败处理
POST /api/lessons/build为某个 path unit 创建单节生成任务。run_id、lesson_id、unit_id、status、estimated_steps、created_at。已存在可复用内容时返回 reused=true，不重复生成和扣费。
GET /api/lessons/jobs/{run_id}查询生成过程进度。current_node、nodes[]、progress、elapsed_seconds、status、error_code、recoverable。发现缓存已写入但任务仍 running 时自动 reconcile 为 succeeded。
GET /api/lessons/{lesson_id}读取已生成的 LessonFlow。LessonSpec、LessonFlow、ResearchPack、QualityReport、schema_version。新字段缺失时走 LessonAdapter 降级。
POST /api/lessons/{lesson_id}/runtime保存用户在学习页的选择、输入、完成步骤和产出。current_step、completed_steps、selected_options、free_inputs、outputs、updated_at。重复保存必须幂等，不覆盖用户手写内容。
POST /api/lessons/{lesson_id}/regenerate用户带要求重生成。revision_request、base_lesson_id、new_run_id、reason、keep_previous=true。失败时保留旧版本可继续学习。

技术方案拆解

把单节内容生产线拆成可实现、可观察、可验收的组件。

Tech Plan
层级组件职责关键字段 / 接口
输入层LearningIntent承接对话摸底后的学习目标、用户水平、约束、偏好和本节主题。goal、domain、level_signal、use_case、time_budget、constraints、preferred_sources。
研究层ResearchPack决定是否联网，收集并分类本节参考来源，给后续生成提供事实锚点。queries、sources、source_type、authority_score、used_for、missing_reason。
课设层LessonSpec把资料和学习目标转成一节课的教学设计。learning_question、outcomes、prerequisites、depth_level、misconceptions、practice_goals。
生成层LessonBuildGraph执行 research → design → draft → critic → revise → persist。run_id、node_status、node_input、node_output、duration_ms、error_code、retry_count。
内容层LessonFlow保存 8 个学习环节及每个环节的卡片内容、互动题、产出任务和来源引用。cards[]、step_type、prompt、options、answer_schema、source_refs、completion_rule。
质检层QualityReport判断内容是否足够深、准确、可学、可交互、可展示。depth_score、source_coverage、interactivity_score、clarity_score、risk_flags、revision_plan。
运行层LessonRuntime管理用户学习状态、回看、输入保存、完成判定和资料沉淀。current_step、completed_steps、selected_options、free_inputs、outputs、saved_at。
兼容层LessonAdapter把旧 explain/practice/produce 数据映射成最小可渲染结构，避免旧数据失效。schema_version、legacy_fields、fallback_cards、migration_notes。

生成与质检流程

用户看到的是一节课，系统内部必须是一个可收敛的 Loop。

Flow
阶段系统动作用户侧呈现失败处理
理解目标读取 LearningIntent、路径上下文和本节主题，确认本节要解决的问题。生成页显示“正在理解学习目标”。缺少目标时回退到路径主题和本周目标。
收集资料按主题判断是否联网，生成查询，收集网页/文档/视频/B站等来源。显示“正在整理参考来源”。搜索失败时保留 missing_reason，使用本地 RAG 和通用知识降级。
设计教学链生成 LessonSpec，确定 8 环节节奏、互动点、产出任务和来源引用位置。显示“正在设计学习任务”。Spec 不完整时重试一次；仍失败则保存失败原因。
生成内容生成 LessonFlow，包括讲解、练习、结构图、例子和参考来源。显示“正在生成讲解与练习”。模型输出结构不合法时修复或重试。
质量审查用 QualityReport 检查深度、准确性、来源、互动和页面可读性。显示“正在做质量审查”。低于阈值自动返工一次；超过预算则给重试入口。
保存与打开持久化 LessonFlow、ResearchPack、QualityReport 和 Runtime 初始状态。打开学习页，第一步可直接开始。保存失败时不扣重复积分，保留 run_id 供恢复。

单节学习体验规格

V0.46 的前端验收不能只看内容生成成功，还要看学习节奏是否成立。

UX
环节用户看到什么系统要做什么不能出现
1 先想一个能判断已有认知的问题，选项 + 补充输入。激活先验知识，记录用户判断，不要求答对。开放到用户不知道怎么答；选项自动灌入输入框。
2 看懂结构化讲解、关键概念边界、来源依据。把概念讲清楚，避免只给定义。大段无结构文字；没有来源。
3 自己讲让用户用自己的话复述或举例。检查是否能解释，而不是只看完。只有“继续”按钮，没有输出。
4 动手小任务、案例拆解、流程搭建或判断题。把知识转成可操作动作。任务太泛，如“请实践一下”。
5-7 练习由易到难的 3 个练习，最好有真实场景。覆盖理解、迁移、应用三个层次。题目只测记忆；选项模糊。
8 收束本节总结、错点、下一步建议、参考来源。形成可复习材料，并写入学习数据。学完即结束，没有沉淀。

非目标与边界

避免 V0.46 越做越大。

Out of Scope
本版本不做：整条路径自动重规划、后台每日经营分析、跨周预生成策略、积分定价调整、真实视频内容解析。V0.46 只把“单节课能不能生成好、能不能学得顺”打穿；路径级闭环放到 V0.47。

内部里程碑

这些是开发阶段，不再单独作为产品版本。

Milestones
里程碑目标验收
M1 数据契约与评测集把好内容的输入、输出、来源和质量报告定成稳定结构。旧数据兼容，多领域 fixture 可跑，来源包可记录网页/文档/视频。
M2 单节 LessonBuildGraph让一节课经过研究、课设、出稿、质检、返工和保存。低质量内容会返工，生成结果可恢复，可带要求重生成。
M3 学习页运行时把内容渲染成清晰学习任务流。已学可回看，选项和输入分离，结构图可读，桌面/移动端不拥挤。
M4 验收与兼容完整端到端可发版。用户能完成一节高质量学习内容；过程、来源、质量报告可追踪。

发版验收

这个版本必须让用户感知到学习内容质量升级。

DoD
发版标准：至少用 6 个不同领域学习目标完成端到端验收，系统能生成一节带来源、带互动、带产出任务、可回看、可重生成且通过质量门的学习内容；其中至少 2 个主题包含外部权威链接，至少 1 个主题包含视频/B站参考链接；旧路径仍可打开，不影响线上数据。
验收项通过标准
内容深度用户能从页面上看出“本节解决什么问题、学完能做什么、为什么这样做”。
互动有效先想、判断、复述、练习和产出都记录用户行为，不是纯点击继续。
来源可信来源能打开，且标明用于事实依据、延伸阅读还是视频参考。
过程可见生成超过 10 秒时用户能看到阶段进度；超时或失败有恢复入口。
兼容稳定旧数据、新数据、重生成版本都能打开；不会重复扣积分或丢学习记录。
