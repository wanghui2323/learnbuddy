教学内容 Loop Engine 的方案母版

V0.44 不代表功能已开发完成，而是把 AI-Shifu 调研、Loop 工程文章、当前内容质量问题和产品判断收敛成后续 V0.46/V0.47 的拆解依据。

状态：方案档案作用：母版下游：V0.46/V0.47

需求方案

把“内容浅、来源弱、互动差、等待焦虑、生成不可控”收敛为可开发需求。

  • 每节课要说明本节解决什么问题、学完能做什么、依据什么来源。
  • 允许网页、论文、文档、视频/B站作为学习参考源。
  • 生成过程要让用户看到搜索、设计、生成、质检和保存状态。
  • 学习页要从长文本展示变成有节奏的任务流。

技术方案

形成 Content Loop Engine 的骨架。

  • 核心契约：LearningIntent、ResearchPack、LessonSpec、LessonFlow、QualityReport、RunSheet。
  • 核心流程：目标接地 → 深度资料收集 → 教学链设计 → 内容生成 → Critic → 返工 → 保存。
  • 长任务必须有 job/status、硬超时、恢复和重试。
  • 所有新增字段兼容旧实例，缺失时降级读取。

开发范式

按可发版产品版本推进，工程阶段只作为内部里程碑。

  • V0.46 教学内容 Loop v1：合并契约、单节生成和学习页运行时。
  • V0.47 路径级 Loop v1：视 V0.46 验证情况推进路径级预生成和后台分析。
  • 每个版本都要有独立三件套页面，不能只是一段技术阶段。

验收清单

V0.44 的验收是“方案是否能指导后续开发”，不是线上功能验收。
