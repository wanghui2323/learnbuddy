### P1 - 重要（产品成型）

| # | 项目 | V0 现状 | V1 目标 |
|---|---|---|---|
| **P1-1** | **持续运营仪表盘** | 只有实例展示页 | today / calendar / progress / instances 多页面（参考原项目）|
| **P1-2** | **月末 R11 评估 + 自动节奏调整** | 写在愿景契约 markdown | 月末自动跑评估对话 / adjustments-log 持久化 / 自动 W2-WN 重新生成 |
| **P1-3** | **后续周 lazy build** | 只生成 W1.json | 进入 W2 时自动调 LLM 生成 W2.json，结合 W1 学习反馈 |
| **P1-4** | **翻译层原则**（继承自原项目）| 无 | 任何 LLM/工程动作都给"业务语义 + 风险提示"自然语言翻译 |
| **P1-5** | **学习画像逐步成型** | 仅 baseline_summary | 累积 N 周学习行为 → 重新生成 system prompt 让 AI 教练越来越懂用户 |
| **P1-6** | **手动调整对话** | 只能首次生成 | "我想把强度从 standard 调到 conservative" → 局部重生 |

### P2 - 工程底线（生产级前置）

| # | 项目 | V0 现状 | V1 目标 |
|---|---|---|---|
| **P2-1** | **密钥安全** | .env 本地文件 | KMS / Vault / GCP Secret Manager |
| **P2-2** | **环境隔离** | 单环境 | dev / staging / prod 三环境 + 独立 DB |
| **P2-3** | **行级权限** | 无 | PostgreSQL RLS + JWT |
| **P2-4** | **备份与回滚** | 无 | 每日自动备份 / 用户可一键导出全部数据 |
| **P2-5** | **鉴权与限流** | 无 | per-user rate limit / API key 轮转 |
| **P2-6** | **LLM 兜底** | evaluator 有 fallback；engine / generator 弱 | 全链路超时 / 重试 / 降级到 fallback prompt |
| **P2-7** | **可观测性** | print | structured logging / Datadog / Sentry |
| **P2-8** | **隐私合规** | 无 | 用户可完全删除全部数据；不存敏感字段 |

### P3 - Claude Agent SDK 5 大模式（V2 重点）

| # | 模式 | V1 状态 | V2 目标 |
|---|---|---|---|
| **P3-1** | **Durable State** | session 内存丢失 | 对话历史持久化到 DB，可恢复任意时点 |
| **P3-2** | **Cost Caps** | 无 | per-user 月度 token 预算 + 提醒 |
| **P3-3** | **Circuit Breakers** | 无 | LLM 异常时自动切到 fallback model（claude-haiku 等）|
| **P3-4** | **Tool Permission** | 无（V0 没有 tool）| V2 引入工具调用时给细粒度权限（读 vs 写 vs 删） |
| **P3-5** | **Eval Hooks** | smoke + pytest | 真实用户对话录制 + 自动 eval（生成质量 / 完整度 / 准确性）|

## V0 暴露的具体待修问题

> 这些是 V0 端到端跑通过程中实际碰到、有明确 reproducer 的问题。

| ID | 描述 | 复现 | 严重度 | 已记录到 |
|---|---|---|---|---|
| **V0-#1** | LLM 出题选项重复 | `python scripts/eval_demo.py "日语 N3 备考"` 偶发"窓が開けてある"出现 3 次 | 中 | P0-4 |
| **V0-#2** | _index.json 与磁盘目录不同步 | 删 _index.json 但保留实例目录 → /api/instance/{id} 仍能返回，但 /api/instances 显示 count=0 | 低 | P0-3 |
| **V0-#3** | session 重启丢失 | 重启 server 后浏览器原 session_id 失效，需 reset | 中 | P0-3 / P3-1 |
| **V0-#4** | 不能"边对话边查现有实例" | 只有 GENERATE 触发后才能看到实例页 | 低 | P1-1 |
| **V0-#5** | W2-WN 内容空 | master.json 的 W5+ 显示"待对话补充" | 中 | P1-3 |
| **V0-#6** | LLM 选错参数包字段会致解析失败 | 比如 LLM 把 weeks 写成字符串 → extract_generate_params 返回 None，用户没有明确反馈 | 中 | 加错误提示 UX |

## 不做的（明确划出）

为了 V1 不变成无底洞，明确不做：

- **强实操依赖型领域**（钢琴 / 烹饪 / 化学实验）—— V2 才考虑接入硬件 / 视频反馈
- **课程内容生产**（不是 Coursera 平台，不卖课程，不做内容）
- **社交 / 师生匹配**（不是教育机构，不做撮合）
- **AI 替你学**（拒绝"AI 帮你做作业"路线，LearnBuddy 给的是脚手架不是答案）

---

> **原则**：V1 永远先做"让 V0 能更稳"的事，再做"让 V0 能更大"的事。
