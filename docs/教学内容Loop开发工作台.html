本页只保留 V0.44 专项结论：LearnBuddy 的教学内容生成要从“Prompt 出稿”升级为可检查、可返工、可恢复的内容生产 Loop。全项目需求、技术方案和进度请回到主工作台按版本号查看。

本期结论

这页不再承担长期工作台职责，只作为 V0.44 专项档案。
V0.44
产品

内容必须能被学习

每节课要回答本节解决什么问题、学完能做什么、依据什么来源、怎么互动、怎么验收。

技术

生成必须形成闭环

目标接地、资料研究、课设规划、内容生成、质量审查、定向返工和保存运行单。

边界

先协议后重构

先固化数据契约和测试集，不一次性引入复杂自由 Agent，不破坏线上实例。

Loop Map

V0.46 之后的实现要围绕这条链路拆解。
Content Loop
阶段目标关键产物
目标接地识别学习命题、多义词、目标产出和是否需要联网。LearningIntent
资料研究收集网页、文档、视频/B站、课程和案例来源。ResearchPack / source_pack
课设规划先设计本节问题、学完能做、主线、互动和验收。LessonSpec
内容生成按先想、看懂、图解、例子、动手、练习、收束组织。LessonFlow
质量审查检查深度、准确性、来源覆盖、互动性和可读性。QualityReport
返工保存定向返工不合格部分，并保存阶段、耗时、来源和结果。RunSheet

后续数据契约

下一版 V0.46 从这些对象开始实现。
V0.46 输入
  • LearningIntent：领域、目标产出、水平、投入、偏好、约束。
  • ResearchPack：网页、文档、视频/B站、书、课程、案例，含摘要和适用环节。
  • LessonSpec：本节问题、学完能做、主线、图解需求、互动点、验收点。
  • LessonFlow：8 环节结构、每环节动作、输入输出、可回看状态。
  • QualityReport / RunSheet：质量分、失败原因、返工建议、生成阶段、缓存路径。
